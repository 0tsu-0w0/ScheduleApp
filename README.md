# ScheduleApp(Nora Schedule 改造版)

予定、ToDo、Dデイ、メモ、食事・運動、読書・TRPGの記録、集中時間までを1か所で管理する、軽いデスクトップ用スケジュールアプリです。
データはすべて自分のPCに保存されます。

## 元のNora Scheduleから変えたところ

### Googleカレンダーの予定の取り込み(閲覧のみ)

Googleカレンダーの予定を、このアプリのカレンダーに表示できるようにしました(Google → アプリの一方向)。設定方法は [docs/google-calendar.md](docs/google-calendar.md) にあります。

- **初期状態はオフ**: 設定画面で接続するまで、Googleとは一切通信しません
- **権限は読み取りだけ**: Googleに求める権限は `calendar.readonly` だけです
- **認証情報の保管**: クライアントシークレットとリフレッシュトークンは、OSの資格情報ストア(Windows資格情報マネージャー / macOSキーチェーン)に保存します。データベースやバックアップには入りません。バックアップを別のPCで復元した場合は、もう一度接続が必要です
- **カレンダーの選択**: アカウント内のカレンダーごとに「取り込む」「表示する」を切り替えられます
- **更新のタイミング**: 起動時、「今すぐ更新」ボタン、自動更新(5分〜3時間から選択)。APIの回数制限に当たったときは、間隔を空けて再試行します
- **オフライン時**: 前回取り込んだ予定をそのまま表示し、最終更新時刻とエラー内容を設定画面に出します
- **見た目**: 取り込んだ予定は、薄い背景色と左端の色帯で、自分の予定と区別できます
- **操作**: 取り込んだ予定はドラッグ・編集・削除できません。クリックで読み取り専用の詳細が開き、「Googleカレンダーで開く」ボタンがあります。右クリックで「自分の予定として複製」もできます
- **通知**: 取り込んだ予定にも、自分の予定と同じシステム通知と通知音を出せます。設定で「なし」(初期値)/「Googleの設定どおり」/ 5・10・30・60分前 から選びます。「Googleの設定どおり」は、予定ごとのポップアップ通知の時間を使い、個別の設定がない予定はカレンダーの既定の時間を使います
- **表示言語**: 追加した文言は日本語・韓国語・英語の3言語に対応しています

主なファイル:

| ファイル | 役割 |
|---|---|
| `src-tauri/src/gcal.rs` | 認可(ループバック+PKCE)、Google API呼び出し、取り込んだ予定の保存、Tauriコマンド |
| `src/lib/gcal.svelte.ts` | 連携の状態と自動更新タイマー |
| `src/components/GoogleCalendarSettings.svelte` | 設定画面の「Googleカレンダー」欄 |
| `src/components/ExternalEventModal.svelte` | 取り込んだ予定の詳細(読み取り専用) |

### 自動バックアップ

手動のバックアップ(設定 → データの「バックアップを書き出す」)と同じファイルを、決まった間隔で自動的に作ります。初期状態はオフです。

- **設定項目**: オン/オフ、保存先フォルダー、間隔(毎日 / 毎週)、残す数(3・7・14・30個)
- **ファイル名**: `Nora-auto-年-月-日_時分秒.nora`。復元は手動のバックアップと同じく設定 → データの「バックアップを読み込む」から行います
- **古いファイルの削除**: 残す数を超えたら古い順に削除します。削除するのは上の名前のファイルだけで、フォルダー内のほかのファイルには触れません
- **動くタイミング**: アプリが起動している間、1分ごとに期限を確認します。ウィンドウを隠していても動きます。アプリを閉じている間は動かず、次に起動したときに期限が過ぎていれば作ります
- **失敗したとき**: 設定画面にエラーを表示し、1時間後に再試行します。「今すぐバックアップ」ボタンで、すぐに作ることもできます
- OneDriveなどの同期フォルダーを保存先にすると、PCの外にも控えが残ります。Googleの認証情報はOSの資格情報ストアにあるため、バックアップには入りません

主なファイル: `src-tauri/src/autobackup.rs`(期限の確認、書き出し、古いファイルの削除)、`src/components/AutoBackupSettings.svelte`(設定画面の欄)

### 軽量化

元の機能の動き方は変えずに、無駄な処理を減らしました。

- **ページの遅延読み込み**: ホーム以外のページは、初めて開いたときに読み込みます。起動時に読み込むJavaScriptが約697KBから約385KBに減りました
- **ポモドーロのタイマー**: 元は止まっている間も1秒に4回動いていましたが、動いている間だけ刻むようにしました
- **作業時間の取得**: 1〜15秒ごとの問い合わせを、ウィンドウが最小化・非表示の間は止め、表示に戻ったらすぐ取り直すようにしました

フォント(Noto Sans JP 約5.2MB、Pretendard 約3MB)は、オフラインでも表示できるよう、元のまま同梱しています。

## 元から入っている機能

以下は元のNora Scheduleの機能です(元のREADMEの日本語訳)。

### ホーム
- ウィジェットを選んで並べるダッシュボード(あいさつ、今日の予定、カレンダー、ToDo、Dデイ、ポモドーロ、作業時間、週間チャート、メモ、ブックマーク、家計簿、カロリーなど)
- ウィジェットのサイズ変更、ドラッグで並べ替え
- ヘッダー画像と飾り用の画像カード(GIFアニメーション可、ドラッグ・拡大で表示範囲を調整)
- カレンダーウィジェットで日付にマウスを乗せると、その日の予定をプレビュー

### カレンダー
- 月・週・日の表示、ドラッグで予定を作成
- 予定をドラッグで別の日へ移動(週・日表示では15分単位で時刻も移動、取り消し可)
- 複数日にわたる予定を途切れない1本のバーで表示
- 繰り返し予定(毎日・毎週・毎月・毎年、回数/終了日の指定、「この予定のみ / すべての予定」の編集)
- 予定の完了(取り消し線で表示、元に戻せる)
- タグ(色・カテゴリー、タグで絞り込み、先頭のタグの色で表示)
- 事前通知(なし、5分、10分、30分、1時間、ユーザー指定)。通知音とシステム通知
- 予定にマウスを乗せると、時間・場所・タグ・メモを表示
- 締め切りのあるToDoもカレンダーに表示(クリックで完了)
- コピー・貼り付け(Ctrl+C / Ctrl+V、Macは⌘)、右クリックメニュー、取り消し
- 終日予定を時刻のある予定の後ろに並べる設定、時刻の選び方(15分刻みのリスト / 午前・午後+時・分)

### ToDo
- グループ別の管理、サブタスク、締め切り日・締め切り時刻

### Dデイ
- 記念日までの日数と経過日数、カバー写真(GIFアニメーション可)
- カードの形(基本 / 横型 / 縦型)
- 毎年繰り返し(誕生日・記念日)、当日を1日目として数える(付き合った日 = D+1)

### 食事・運動
- 食べたものと食べる予定のものを、朝・昼・晩・間食に分けて記録。ワンタップで「食べた」に変更
- 1日の目標に対する残りカロリー(目標 − 食べたもの + 運動消費)、予定の分まで食べたときの余り・超過
- 12種類の運動と運動時間の記録、体重から消費カロリーを自動計算(体重 × 運動強度(MET) × 時間、手入力も可)
- 直近7日間の状況、最近食べたものをまとめて再追加

### 読書
- 読書中 / 読みたい / 読了
- 読んだページ数と進捗率、開始日・読了日、評価、感想
- 本棚表示とリスト表示、検索と並べ替え、今年読んだ冊数

### TRPG
- プレイしたシナリオ(セッション)の記録と、やりたいシナリオのリスト
- プレイ済みシナリオをフォルダーで整理(例: CoCタイマン、CoC多人数)、役割の複数選択(GM・PL・HO1〜5・PC1〜5、自由入力)
- ルールブック・シナリオブックの本棚(表紙、著者・出版社)
- 分析レポート: 月別・年別のセッション数、よく使うルール、よくプレイする作家

### メモ
- リッチテキスト編集、自動保存
- グループで整理(ドラッグ&ドロップで移動)

### その他
- **ポモドーロ**タイマーと集中の記録
- **作業時間の記録**: 指定したアプリで過ごした時間だけを記録、離席の検知、アプリ・ウィンドウタイトル別の集計
- **分析**: 集中時間、ToDo完了数、作業時間のチャート
- **ブックマーク**(フォルダー、ドラッグで並べ替え)、**家計簿**
- **オーバーレイパネル**: デスクトップ上に浮かぶ小さなウィジェットパネル(画面の隅に吸着、他のウィンドウの手前に固定、折りたたみ・展開、ログイン時の自動起動)

### 見た目と設定
- ライト / ダーク / システム連動のテーマ、色テーマのプリセットと自作(メイン色、補助色、背景の色味)
- Windowsのタイトルバーの色がテーマに追従
- ステッカー: 自分の画像(透明PNG、GIFアニメーション含む)を好きなページに貼って、移動・サイズ変更・回転(デコレーションモードのときだけ編集でき、普段はクリックの邪魔をしない)
- 한국어 / English / 日本語。フォントはPretendard(日本語はNoto Sans JP)をアプリに同梱し、オフラインでも表示
- サイドバーのページの並べ替え・非表示
- 画面の拡大率の変更
- ウィンドウのサイズ・位置の記憶、サイズのプリセット
- 全データのバックアップ・復元(画像、食事・運動、読書・TRPGの記録を含む)、初期化

## 技術スタック

| 領域 | 使用技術 |
|---|---|
| アプリの枠組み | [Tauri 2](https://tauri.app)(Windows: WebView2、macOS: WKWebView) |
| バックエンド | Rust(edition 2024)、SQLite([rusqlite](https://github.com/rusqlite/rusqlite)、バンドルビルド)、chrono、serde、image、zip |
| フロントエンド | [Svelte 5](https://svelte.dev)(runes)、TypeScript、Vite |
| エディター | [Tiptap 3](https://tiptap.dev)(Markdown対応)、marked、DOMPurify |
| UI | Lucideアイコン、Pretendard・Noto Sans JPフォント、自作のCSSデザインシステム |
| Tauriプラグイン | autostart、dialog、notification、opener、single-instance、window-state |
| 作業時間の記録 | active-win-pos-rs(アクティブなウィンドウの取得) |
| 改造で追加 | ureq(HTTP通信)、keyring(OSの資格情報ストア)、sha2・base64・getrandom(PKCE)、url・urlencoding |

データはOSのアプリデータフォルダー(Windows: `%APPDATA%\com.nora.schedule`、macOS: `~/Library/Application Support/com.nora.schedule`)に、SQLiteファイルと画像フォルダーとして保存されます。保存先は元のNora Scheduleと同じなので、同じPCで両方を使うとデータを共有します。

## 自分でビルドする

必要なもの:
- Node.js 22.12以上(`.nvmrc` を参照)
- Rust(rustup)
- Windows: Microsoft C++ Build Tools、WebView2(Windows 11には標準で入っています)
- macOS: Xcode Command Line Tools(`xcode-select --install`)

```sh
npm install
npm run tauri dev      # 開発モードで起動
npm run tauri build    # インストーラーを作成
```

ビルドの成果物は `src-tauri/target/release/bundle/` の下にできます(Windows: `nsis/…-setup.exe`、`msi/….msi` · macOS: `macos/Nora Schedule.app`、`dmg/….dmg`)。

その他のコマンド:

```sh
npm run check                  # フロントエンドの型検査
cd src-tauri && cargo test     # バックエンドのテスト
```

開発中に本番のデータではなく別のフォルダーを使うには、環境変数 `NORA_DATA_DIR` で指定してください。
