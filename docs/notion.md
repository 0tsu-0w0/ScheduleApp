# Notion連携(書き出し)

メモ・読書記録・TRPG記録を、自分のNotionのデータベースへ書き出します(アプリ → Notion の一方向)。要件定義書の FR-13、issue #5 にあたります。初期状態はオフです。

## できること

- 種類(メモ / 読書記録 / TRPG記録)ごとに、書き出し先のデータベースを選ぶ。すでにあるデータベースを使う
- アプリの項目と、データベースのプロパティの対応を選ぶ。読み込んだときに、同じ名前のプロパティを自動で当てはめる
- メモの本文・読書の感想・TRPGのメモ(Markdown)を、ページの本文として書き出せる
- 手動の「書き出す」「今すぐすべて書き出す」と、5分ごとの自動書き出しを選べる
- 同じ項目を何度書き出しても重複しない。変わっていない項目は通信もしない
- アプリで消した項目は、Notionのページをアーカイブする

Notionで直した内容はアプリに戻らず、次の書き出しで上書きされます。

## 初回の準備

1. [Notionのインテグレーション設定](https://www.notion.so/profile/integrations) で「内部インテグレーション」を作り、シークレットをコピーする
2. 書き出し先の各データベースを開き、右上の ··· →「接続」から、作ったインテグレーションを追加する
3. 設定 →「Notion」にシークレットを貼り付けて「接続」
4. 種類ごとに「設定…」を押し、データベースのリンクを貼って「読み込む」。項目の対応を確かめて「保存」

## 項目とプロパティの型

| アプリの項目 | 書き出せるプロパティの型 |
|---|---|
| 文字(タイトル、著者、状態、種類、グループなど) | タイトル、テキスト、セレクト、マルチセレクト、ステータス |
| 役割(TRPG、複数) | マルチセレクト、テキスト、セレクト(先頭の1つ) |
| 数(ページ数、進捗%、評価) | 数値、テキスト |
| 日付(作成日、読了日など) | 日付、テキスト |
| リンク(TRPG) | URL、テキスト |

- データベースのタイトルのプロパティには、対応を選ばなくても項目のタイトルを入れます
- セレクトの選択肢は、無ければNotionが自動で作ります。ステータスは自動で作られないため、同じ名前の選択肢を先に作っておく必要があります
- 状態や種類は、アプリの表示言語の名前で書き出します(例: 読んでいる本、遊んだ)
- 評価は星の数(0.5刻み、未評価は空)、進捗はページ数が分かる本だけ書き出します

## 本文の変換

Markdownを次のNotionブロックに変換します: 見出し(1〜3)、段落、箇条書き、番号付きリスト、チェックリスト、引用、コード、区切り線。太字・斜体・取り消し線・インラインコード・リンクも保ちます。

- 画像、表、HTMLは書き出せません。その数を設定画面に表示します
- 入れ子のリストは1段までにまとめます

## データの扱い

| 何を | どこに |
|---|---|
| インテグレーションのシークレット | OSの資格情報ストア。SQLiteにもバックアップにも入らない |
| 書き出し先、項目の対応、自動書き出しの設定 | SQLiteの `settings` テーブル(キー `notion`) |
| どの項目をどのページに書いたか、送った内容のハッシュ | SQLiteの `notion_pages` テーブル |

- 連携を解除しても、書き出し先の設定とページの対応表は残します。もう一度接続すれば、同じページを更新します
- Notion APIのバージョンは `2022-06-28` を使います

## 実装の場所

- `src-tauri/src/notion.rs` — 項目の読み出し、Markdownの変換、書き出し、自動書き出し、Tauriコマンド
- `src/components/NotionSettings.svelte` — 設定画面
