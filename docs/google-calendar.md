# Googleカレンダー連携(閲覧のみ)

Googleカレンダーの予定を、Nora Scheduleのカレンダーに取り込んで表示します(Google → Nora の一方向)。要件定義書の FR-12.1〜12.6 にあたります。

## できること

- 自分のGoogleアカウントで認可し、連携を許可・解除する
- アカウント内のカレンダーから、取り込むもの・表示するものを選ぶ
- 繰り返し予定、終日予定、複数日予定を表示する(繰り返しはGoogle側で展開済みの1回ずつを取り込む)
- 取り込んだ予定は薄い色+左端の色帯で表示し、Noraの予定と区別する。ドラッグ・編集・削除はできない
  - クリックで詳細(読み取り専用)、右クリックで「Googleカレンダーで開く」「自分の予定として複製」
- 起動時、「今すぐ更新」ボタン、一定間隔(5分〜3時間)で自動更新する
- 通信できないときは前回取り込んだ予定をそのまま表示し、最終更新時刻とエラーを設定画面に出す

取り込む範囲は、今日の180日前から400日後までです。

## 初回の準備(Google Cloud側)

配布用の共通クライアントは用意していないため、自分用のOAuthクライアントを作ります。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作る
2. 「APIとサービス」→「ライブラリ」で **Google Calendar API** を有効にする
3. 「OAuth同意画面」を設定する。公開ステータスは「テスト」のままでよい。テストユーザーに自分のGoogleアカウントを追加する
4. 「認証情報」→「認証情報を作成」→「OAuthクライアントID」→ 種類は **デスクトップ アプリ**
5. 表示されたクライアントIDとクライアントシークレットを控える

## 接続

1. Nora Scheduleの「設定」→「Googleカレンダー」に、クライアントIDとシークレットを貼り付けて「接続」
2. ブラウザでGoogleの同意画面が開くので、許可する(テスト中のアプリという警告が出たら「続行」)
3. 「Googleカレンダーと接続しました」と表示されたらタブを閉じてアプリに戻る

最初はメインのカレンダーだけが取り込まれます。ほかのカレンダーは一覧のスイッチで選んでください。

## データの扱い

| 何を | どこに |
|---|---|
| クライアントシークレット、リフレッシュトークン | OSの資格情報ストア(Windows資格情報マネージャー / macOSキーチェーン)。SQLiteにもバックアップにも入らない |
| クライアントID、選んだカレンダー、更新間隔、最終更新時刻 | SQLiteの `settings` テーブル(キー `gcal`) |
| 取り込んだ予定 | SQLiteの `gcal_events` テーブル(オフライン表示用のキャッシュ) |

- 求める権限は `calendar.readonly`(読み取りのみ)です
- 接続するまで、Googleとは一切通信しません。「連携を解除」でトークンを失効させ、資格情報と取り込んだ予定を削除します
- バックアップを別のPCで復元すると、トークンは移らないため「もう一度接続してください」と表示されます

## 実装の場所

- `src-tauri/src/gcal.rs` — OAuth(ループバック+PKCE)、API呼び出し、キャッシュ、Tauriコマンド
- `src/lib/gcal.svelte.ts` — 状態と自動更新タイマー
- `src/components/GoogleCalendarSettings.svelte` — 設定画面
- `src/components/ExternalEventModal.svelte` — 取り込んだ予定の詳細(読み取り専用)
